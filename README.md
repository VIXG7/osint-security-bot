# 🔎 OSINT Security Bot

> Educational OSINT tool for checking publicly available username profiles.

## 📌 About

OSINT Security Bot is an educational cybersecurity project developed in Python.

The tool checks whether a username is publicly available on selected online platforms.

The project is designed to practice:

- 🐍 Python
- 🌐 HTTP requests
- 🔎 OSINT fundamentals
- 🛡️ Cybersecurity
- 🐙 Git and GitHub

## ⚙️ Currently Supported

The current version checks:

- GitHub
- GitLab
- Reddit
